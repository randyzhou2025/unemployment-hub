# 资讯移除与入口保留

本轮按用户确认，移除小程序的资讯展示，保留首页“失业金、社保医保、培训补贴”三个入口及对应功能。三个模块仍展示政策数据、参保方案和补贴项目，本轮不等于纯工具化，也不代表微信审核已通过。

## 前台变化

- 底部导航改为：首页、待办、工具、我的。
- 移除资讯列表、文章阅读、内容搜索、资讯专题的页面与路由。
- 首页保留三个模块，下方展示本机预算、未完成事项和求职进度。
- 三个保留模块不再请求、展示或推荐资讯文章。
- 待办支持直接添加个人事项；阶段模板以操作清单展示，不再呈现文章正文。
- 收藏页仅展示事项清单与官方渠道；历史文章收藏留在本机及备份中，无法再打开阅读。
- 原待办链接继续进入新的待办标签；预算、任务、求职记录的本机存储键与数据格式保持兼容。

## 后台与接口

历史文章、草稿和发布记录留在数据库，padmin 继续管理，不删除数据。管理工作台会提示文章不再向小程序展示。

- 公共内容列表与搜索排除 `article`；显式查询文章返回空列表。
- 已发布文章的公共详情、状态、清单及渠道接口均返回 404。
- 清单、官方渠道、失业金政策、社保医保和培训补贴接口继续提供服务。

## 上线顺序

1. 更新服务器 API 和随 API 镜像构建的管理工作台，无需数据库迁移、清空或重新导入数据。
2. 执行 `pnpm release:weapp`，将 `apps/miniapp/dist/build/mp-weixin` 导入微信开发者工具验收。
3. 按实际保留功能核对微信后台简介、服务类目及备案内容，再上传和提审。本地编译成功不代表平台已认可当前服务范围。

代码更新后，服务器部署、微信上传和提审仍需分别执行验收。
