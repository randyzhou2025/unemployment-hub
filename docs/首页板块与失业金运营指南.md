# 首页板块与失业金运营指南

适用项目：`/Users/Randy/Cursor/UnemploymentHub`。

## 1. 从哪里管理

本机后台：http://localhost:3071/ 。上线后使用部署文档中配置的 HTTPS 后台域名。

| 后台菜单 | 用途 |
| --- | --- |
| 首页板块 | 新增、移除、排序入口；修改名称、说明、图标、颜色和跳转分类；控制首页显示 |
| 失业金政策 | 维护上海的金额卡片、政策有效期、核查与复核日期、政策要点和官方原文 |
| 内容与指南 | 编辑、审核、发布资讯、阶段指南、官方渠道 |
| 工具管理 | 暂停或恢复失业金金额试算等工具入口 |
| 操作记录 | 查看配置发布和内容操作记录 |

管理员和审核员可以发布配置，编辑员可以查看。保存板块、政策配置会直接更新公开接口；资讯保留既有草稿、审核、发布流程。

## 2. 首页板块

初始为七个板块：失业金、失业指南、社保医保、离职权益、培训补贴、求职指南、防骗指南。

1. 在“首页板块”新增一行，填写名称和简短说明。
2. 选择跳转内容：失业金专题，或失业指南、社保医保、离职权益、培训补贴、求职转型、防骗、生活安排的资讯分类。
3. 选择图标与颜色，开启“首页显示”；新行默认隐藏，填写完整后再显示。
4. 用上下箭头调整顺序，点击“保存并发布板块”。
5. 小程序返回首页或下拉刷新后核对结果。

最多18个板块，也允许0个。隐藏和移除只改变首页入口，不删除已发布资讯。新增板块可以指向现有专题或分类；新增一种内容分类或新的工具页面仍需要开发，后台不支持填写任意代码路径。

本机保留最近成功获取的入口配置，断网时继续使用并显示更新提示。后台设置全部隐藏后，空数组也会正常保存，不会被默认入口覆盖。

## 3. 失业金专题的呈现顺序

1. 地区核心数据卡：第1–12个月、第13–24个月、符合条件的延长领取标准；一次核定最长期限。
2. 申领要点，包括条件、期限核定、审核发放、原领取人员衔接、延长领取、医保及停发。
3. 官方原文链接：点击复制，在浏览器查看。
4. 该地区及全国通用的“失业待遇”资讯，按平台发布时间排序，支持继续加载。
5. 失业金金额试算、申领准备清单、官方办理渠道。

目前地区范围仍为上海、全国通用。全国模式不展示上海的金额，也不把上海政策当成全国政策。

## 4. 政策数据及核查

初始版本于2026-10-22核查：

| 项目 | 当前配置 |
| --- | --- |
| 第1–12个月 | 2340元/月 |
| 第13–24个月 | 1872元/月 |
| 符合条件的延长领取 | 1690元/月 |
| 金额标准执行日期 / 文件有效期截止 | 2026-07-01 / 2028-06-30 |
| 申领办法施行日期 / 有效期截止 | 2026-08-16 / 2031-08-15 |
| 一次核定期限上限 | 24个月 |

金额依据：[沪人社规〔2026〕7号](https://rsj.sh.gov.cn/tshbx_17729/20260702/t0035_1442080.html)；申领与期限依据：[沪人社规〔2026〕18号](https://rsj.sh.gov.cn/tshbx_17729/20260812/t0035_1443067.html)。

原领取人员存在衔接安排，核查时同时参阅[官方政策问答](https://rsj.sh.gov.cn/tzcjd_17352_17352/20260812/t0035_1443066.html)和[原领取人员衔接答疑](https://rsj.sh.gov.cn/tlqtj_17563/20260817/t0035_1443150.html)。

“失业金政策”中的金额输入单位是元，接口和数据库使用整数分。金额标准与申领办法分别填写生效、截止日期，不能混用。

每次实际核查后维护“最近实际核查日期”和“下次复核日期”。初始下次复核日期为2026-11-21，部署和保存不会自动延期。超过复核日期、政策文件到期或未生效时，专题显示对应提示，试算暂停提供。历史数据仍可查看，官方原文仍可复制。

## 5. 发布相关资讯

在“内容与指南”中新增资讯，选择：

- 关注内容：失业待遇。
- 适用范围：上海资讯选“指定地区 → 上海”；确为全国通用的内容才选择全国。
- 政策解读：关联官方资料来源，并设置执行期限与复核日期。
- 保存草稿 → 提交审核 → 发布。

不需要把文章再复制到专题中。专题按分类和适用地区自动归集；撤回后公开列表不再提供该文章。

## 6. 金额试算口径

采用用户确认的第一版范围：输入官方已核定的该次完整领取月数，以及该次已实际领取月数，试算剩余分段金额。不会按缴费年限推断资格或待遇期限。

例如，核定24个月、已领取12个月，剩余12个月按1872元/月，合计22464元；核定24个月、尚未领取，按现行标准静态计算合计50544元。

试算保留原核定序号，不会把已领到第13个月的人员重新放回第一档。金额以整数分计算；不包含延长待遇、跨次待遇合并、停发等特殊情况，也不承诺未来标准保持不变。输入不上传，不在服务器保存个人待遇信息。

## 7. 数据在哪里

| 数据 | 存储位置 |
| --- | --- |
| 首页入口配置 | PostgreSQL `app_config`，键 `homeSections` |
| 上海结构化政策 | PostgreSQL `app_config`，键 `benefitPolicy:310000` |
| 工具暂停配置 | PostgreSQL `app_config`，键 `disabledTools` |
| 资讯、指南、渠道 | `contents` 的草稿、`content_revisions` 的发布快照 |
| 来源 | 政策配置内的来源及内容管理的资料来源记录 |
| 首页入口离线缓存 | 手机本机 `uhb:v1:home-sections` |
| 失业金试算输入与结果 | 页面内存，本机计算，不上传 |

新数据沿用既有 `app_config` 表，不需要新增表。首次部署运行原有迁移、初始化命令；本次初始化会补齐两个配置键，已有配置不会被覆盖。缺少配置键的旧库暂时使用已核查的内置初始值，后台首次保存后以数据库为准。后续政策更新应在后台操作，重新执行初始化不会覆盖运营修改。

先更新 API 和后台，再上传对应小程序构建。完整服务器操作参见[部署上线指南](./部署上线指南.md)。数据库备份必须包含 `app_config`。


上线或真机验收至少覆盖：后台隐藏/恢复一个入口、增加并排序一个入口、核对四张核心数据、复制指定官方原文、切换全国模式、打开相关资讯、核定24/已领12的试算、重新返回专题、在工具管理暂停/恢复试算入口。正式环境还须在合法 HTTPS 域名校验开启、手机蜂窝网络下验证。
